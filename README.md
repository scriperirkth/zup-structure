# 🗂️ Структура конфигурации 1С:ЗУП

> Выгрузка метаданных конфигурации **1С:Зарплата и Управление Персоналом (ЗУП)** в формате EDT/XML.  
> Используется как справочник по именам объектов метаданных для разработки, интеграций и написания кода на языке 1С.

---

## 📌 Примечания

- Репозиторий является **справочником структуры** — исходный код модулей хранится внутри поддиректорий каждого объекта.
- Имена объектов используются **без изменений** при обращении в коде 1С на русском языке.
- Конфигурация соответствует типовой **1С:ЗУП (Зарплата и Управление Персоналом)**.
