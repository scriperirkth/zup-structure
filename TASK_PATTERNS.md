# Типовые задачи

## 1. Внешняя обработка
Цель: написать внешнюю обработку на основе структуры конфигурации.
Порядок анализа:
1. Найти документы и справочники.
2. Найти регистры, если нужны данные расчета или истории.
3. Найти существующие общие модули.
4. Найти существующие формы/отчеты/обработки по теме.
5. Предложить структуру обработки.
6. Только потом писать код.

## 2. Анализ документа
Цель: понять, с какими объектами связан документ.
Порядок:
1. Найти объект документа.
2. Найти формы документа.
3. Найти связанные регистры и общие модули.
4. Сформулировать, что еще нужно проверить в живой базе.

## 3. Анализ формы
Цель: понять, где искать реквизиты, команды и поведение формы.
Порядок:
1. Найти форму объекта.
2. Найти модуль формы.
3. Проверить связанные общие модули.
4. Указать, чего может не быть в чистой структуре XML.
