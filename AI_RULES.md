# AI Rules for ZUP Structure

Этот репозиторий — база знаний по структуре конфигурации 1С:ЗУП 3.1.

Правила работы:
1. Всегда сначала ищи подтверждение в файлах репозитория.
2. Не выдумывай объекты метаданных, формы, реквизиты, команды и модули.
3. Если данных в структуре недостаточно, прямо сообщай об этом.
4. Считай этот репозиторий справочником структуры конфигурации, а не данных информационной базы.
5. Для задач на разработку сначала перечисляй релевантные объекты, затем предлагай архитектуру решения, и только потом код.
6. Для задач по внешним обработкам сначала анализируй:
   - документы;
   - справочники;
   - регистры;
   - общие модули;
   - формы;
   - отчеты/обработки, если они уже есть в конфигурации.
7. Если задача касается живых данных базы, отмечай, что структура конфигурации не заменяет анализ содержимого ИБ.
