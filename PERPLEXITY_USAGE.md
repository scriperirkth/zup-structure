# Как использовать этот репозиторий в Perplexity

Используй этот репозиторий как базу знаний по структуре 1С:ЗУП 3.1.

При ответе:
1. Найди релевантные объекты по папкам:
   - Documents
   - Catalogs
   - InformationRegisters
   - CalculationRegisters
   - AccumulationRegisters
   - CommonModules
   - CommonForms
   - Reports
   - DataProcessors
   - Enums
   - ChartsOfCalculationTypes
   - ChartsOfCharacteristicTypes
   - ExchangePlans
   - CommonCommands
   - CommonAttributes
   - CommonTemplates
   - Roles
   - Subsystems
   - ScheduledJobs
   - EventSubscriptions
   - FunctionalOptions
   - DefinedTypes
2. Сначала перечисли найденные объекты.
3. Потом объясни, почему они относятся к задаче.
4. Только после этого предлагай код 1С, запросы или структуру внешней обработки.

Примеры задач:
- найти документы, связанные с кадровым переводом;
- найти регистры и модули, связанные с расчетом зарплаты;
- спроектировать внешнюю обработку по отбору сотрудников;
- найти существующие объекты, которые можно переиспользовать.
